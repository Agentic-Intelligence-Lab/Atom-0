# Atom-CL staged training

Atom-CL transfers representations from ego-centric data to real-robot Piper
fine-tuning through four stages. The canonical operational guide remains
[`docs/egoscale_staged_training.md`](../../docs/egoscale_staged_training.md).

- [Stage 1](stage1): ego-centric pre-training.
- [Stage 2](stage2): robot, aligned, and EgoMimic variants.
- [Stage 3](stage3): Piper and audited real-robot training.
- [Stage 4](stage4): Piper fine-tuning.
