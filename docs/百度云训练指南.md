正式提交前确认：

- `/data/models/paligemma/pt_224.npz` 存在；
- `git status --short` 中没有未确认的代码改动；
- 每次新训练使用一个从未产生过 checkpoint 的 `EXP_NAME`。

如果复用已经存在 checkpoint 的 `EXP_NAME`，训练框架会恢复该实验自身的模型、
optimizer 和 step，而不会重新从 `PARAMS_PATH` 初始化。下面每条命令都使用独立的
`EXP_NAME`；再次重跑时，需要继续更换 `EXP_NAME`。

使用 VLM NPZ 时，任务启动日志应包含：

```text
PARAMS_LAYOUT=paligemma-vlm-npz
INIT_POLICY=PaliGemma vision+language loaded; action expert, timestep MLP, and action projections random
```

## 实验逻辑 

+ A 系列使用筛选前 RLDS：A-1 仅自采 Piper，A-2 为审计后的 Robot 混训，
A-3 在 A-2 完全相同的 34 个数据集基础上加入 5 个 EgoVerse；A-4 再在 A-3
基础上加入 4 个 AtomAligned 和 2 个 EgoVerse RL2。

+ B 系列使用 State-Action 筛选后 RLDS：B-1 仅自采 Piper，B-2 为筛选后的
Robot-only 混训，B-3 为筛选后的 Robot + EgoVerse 混训。B-2/B-3 保留对应
A 系列的主动排除项，并不加载筛选后为空的三个 RoboCOIN builder。

+ A-1/B-1、A-2/B-2、A-3/B-3 分别用于对比筛选前后的仅自采训练、
Robot-only 混训和 Robot + EgoVerse 混训。

+ 进行新的实验时，需要修改EXP_NAME

+ 目前wudi分支的最新代码，已经修改了数据配置的代码，对于piper30数据集，已经自动切换至最新的validation set划分版本。
